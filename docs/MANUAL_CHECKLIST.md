# Ручная проверка Release 1.1 (тестовый бот)

- [ ] `/start`: отображается Release 1.1; основные кнопки работают на русском и английском.
- [ ] `Настройки → Настройки вывода → Дополнительные кнопки`: `Обновить` изначально выключена, включается и выключается.
- [ ] Обычная погода: всегда есть давление; точка росы и видимость отображаются только при выборе.
- [ ] Регион Москва: кнопка «Сделать моим регионом» скрыта и для `Москва`, и для `Moscow`. Для другого города кнопка есть.
- [ ] Обычный результат сравнения: можно сохранить пару и открыть города; при включенной настройке есть «Обновить».
- [ ] Избранное: кнопки 🏙️ городов идут первыми, ⚖️ сравнений — затем; одинаковая пара на двух языках не дублируется.
- [ ] Открыть сохранённое сравнение: только результат и возврат к избранному, без нового сравнения и переходов к городам.
- [ ] Удалить сравнение, затем город: в списке остаются другие записи; нет перепутанных кнопок.
- [ ] Очистить избранное: очищены города и пары; на подтверждении нет кнопки «Избранное».
- [ ] Прогноз по часам: первые 20 точек почасовые, далее до 5 суток с интервалом 3 часа; перелистывание не показывает «Ожидайте».
- [ ] Осадки: дождь 05–08 и снег 06–07 отображаются раздельно; гроза без дождя тоже отображается; времена местные.
- [ ] Кнопки «Назад к погоде» возвращают к тому экрану погоды, откуда открывался прогноз; переходы из избранного и сравнения не путаются.
- [ ] Штормовые предупреждения открываются для Basic и ADV. При отсутствии данных выводится корректное сообщение.
- [ ] Админ-панель: запрос проверки регионов требует подтверждения, не трогает настройки, уровень и избранное; `67` сбрасывается, сетевой сбой не сбрасывает нормальный регион.
- [ ] Чейнджлог: Beta 1.1 слева, Release 1.1 справа; внутри Release 1.1 — две кнопки 🐛 Pre-release на одной строке и «Назад» ниже; возврат идёт к Release 1.1.
- [ ] Перезапуск: старые избранные города, пары и настройки сохраняются в PostgreSQL.
- [ ] Проверить журналы запросов (без токенов) и расходы One Call 4.0 после испытаний.
