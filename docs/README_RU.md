# Weather Bot — Release 1.1

Полная версия Telegram-бота на базе предыдущей Pre-release 1.1-2. Существующие функции сохранены, кроме явно согласованных изменений интерфейса.

## Установка в Visual Studio Code

1. Сделайте резервную копию работающего проекта **и PostgreSQL**.
2. Распакуйте полный ZIP в отдельную папку `beta_weather` и откройте её в VS Code.
3. Перенесите **свой локальный** `.env` из предыдущего проекта. Не копируйте токены в GitHub; файл `.env.example` — только образец.
4. Проверьте Python и зависимости:

   ```bash
   python -m pip install -r requirements.txt
   python -m unittest discover -s tests -v
   python main.py
   ```

5. Сначала используйте тестового Telegram-бота. После ручных проверок запускайте основного.

**Внимание:** PostgreSQL автоматически добавляет колонку `favorite_compares JSONB NOT NULL DEFAULT '[]'::jsonb` в таблицу `users`. Старый список `favorites` остаётся без изменений. На production лучше создать резервную копию перед первым запуском.

Если пользователь уже имеет действующие настройки или избранные города, они сохраняются. Кнопка «Обновить» не появляется, пока её не включат в `Настройки → Настройки вывода → Дополнительные кнопки`.

## Новые возможности

- В едином списке избранного сначала города (`🏙️`), потом сохранённые пары (`⚖️`), без отдельного заголовка.
- Сохранить сравнение можно в обычном результате; сохранённое сравнение не показывает кнопки перехода к городам и нового сравнения.
- Кнопка `Обновить` по умолчанию выключена. Для текущей погоды повторно использует **бесплатный** Current Weather API с ограничителем частоты 30 секунд на пользователя; для сравнения **не обходит** платный 30-минутный кэш.
- Почасовой прогноз: до 20 часовых записей из One Call API 4.0, затем бесплатный пятидневный прогноз с шагом 3 часа. Оба источника кэшируются (в оперативной памяти).
- Отдельные пересекающиеся интервалы дождя, снега и грозы в разделе «Осадки». Для бесплатных трёхчасовых отрезков объём осадков относится к трём часам; пересечение с часовыми данными пропорционально обрезается, чтобы не учитывать одни и те же осадки дважды.
- Штормовые предупреждения доступны любому пользователю при наличии данных у OpenWeather.
- Админ-панель: проверка регионов пользователей с подтверждением и отчётом. При сбое геокодера регион не удаляется; проверка может занимать заметное время на большой базе.
- «Сделать моим регионом» скрывается и для других языковых написаний своего города; обязательное обычное давление остаётся в основной сводке. Лишний показатель «Давление на поверхности» удалён из новых настроек.
- История обновлений: Beta 1.1 слева от Release 1.1, а два Pre-release доступны внутри Release 1.1. Из описания Pre-release 1.1-1 не раскрываются закрытые тесты прошлого релиза.
- После очистки избранного кнопка повторного открытия пустого списка не отображается.

## Ограничения проверки

`unittest` использует искусственные ответы OpenWeather и заглушки Telegram и PostgreSQL. Реальные сетевые запросы, права PostgreSQL на `ALTER TABLE`, работа с токенами, предупреждения по действующим городам, массовая проверка реальной базы и взаимодействия с Telegram нужно проверить вручную.

В публичные файлы не включены никакие действующие API-ключи. Если старые токены когда-либо публиковались, они должны быть перевыпущены.

## Структура исходников

Для удобства основные разделы проекта описаны в [STRUCTURE.md](STRUCTURE.md).
Эта сборка объединяет три небольших вспомогательных модуля с основными:
`weather_conditions.py` и `precipitation_timeline.py` теперь находятся в `weather_format.py`,
а код `favorite_compares.py` и `city_favorites.py` объединён в `favorites.py`.

**Обновляйте проект через распаковку полного архива в новую папку**, а не простое копирование поверх старой: устаревшие файлы в старой папке не удаляются автоматически.
Сохраните локальный `.env` отдельно, затем перенесите его в новую папку.
Настройки PostgreSQL и формат данных не менялись.
